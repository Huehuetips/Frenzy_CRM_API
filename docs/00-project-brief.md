# Mini CRM API - Project Brief

## Objetivo

Construir una API REST para gestión de leads.

## Stack

Node.js + TypeScript + Express + Prisma + PostgreSQL + Docker.

## Alcance

- Auth JWT
- CRUD Leads
- Filtros
- Cambio de estado
- Actividades/notas
- Webhook externo
- Validaciones
- Documentación

## Fuera de alcance

- Frontend
- Roles avanzados
- Recuperación de contraseña
- Notificaciones
- Dashboard
